# 子牙品命 · 八字排盘

免费排盘引流 → 命盘只给骨架 → 引导加微信 → 真人精批成交。

排盘是纯本地计算，没有任何外部调用。**没有可变成本，就不需要会话、额度、
防刷、Redis** ——有人拿脚本狂刷排盘，只花你的 CPU。服务端不持有任何用户状态，
进程重启不丢东西。

## 上线前只有一件事必须做

打开 [`config.py`](config.py)：

1. `WECHAT_ID` 填你的**微信号**（不是昵称——昵称搜不到人）。
2. 把你的二维码存成 `static/wechat-qr.png`，建议 ≥ 430×430。
   不放也能跑，页面会自动只显示微信号和复制按钮。
3. `WECHAT_OFFER` 写清楚加了微信能得到什么。要具体——「了解更多」这类
   空话没人加。

改完重启即可，没有别的必填项。

## 跑起来

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --reload --port 8000
```

打开 http://127.0.0.1:8000 。跑测试：

```bash
python3 -m unittest discover -s tests -v
```

## 排盘精度

这是本项目唯一的护城河——市面便宜的八字 App 大多在这三处出错：

| 规则 | 常见错法 | 本项目 |
|---|---|---|
| 节气时刻 | 查表，覆盖年份有限、边界误差可达数十分钟 | VSOP87 实时推算，实测误差 ±30 秒内 |
| 年柱换年 | 用元旦或农历正月初一 | 立春交接的精确时刻 |
| 月柱换月 | 用农历月或「气」 | 十二「节」交接时刻 |
| 时柱 | 直接用北京时间 | 真太阳时 = 标准时 + 经度时差 + 均时差 |

节气实测（对紫金山天文台/香港天文台公布值）：

```
1984 立春  -29s    2000 立春   -5s    2023 冬至  +10s
2024 立春  +11s    2024 春分  +15s    2024 夏至   +5s
```

已知命例校验：毛泽东 `癸巳 甲子 丁酉 甲辰`、蒋介石 `丁亥 庚戌 己巳 庚午`，
四柱与大运顺逆全中。

**排盘准是引流的前提。** 用户拿别处的盘来对，对不上就不会信你后面的解读。

## 引流设计

漏斗上唯一需要用户动手的地方，摩擦被压到最低：

- **点问题标签 = 把「八字 + 出生信息 + 问题」整段复制好。** 用户加上微信直接
  粘贴就能发出第一条消息，省掉「我该说什么」这一步——这一步正是私域引流
  最常见的流失点。
- **复制微信号按钮。** 手机上无法扫自己屏幕上的二维码，复制加搜索才是真实路径。
- 剪贴板走 `navigator.clipboard`，失败则回落到 `execCommand`。**兜底路径是
  主路径**：这类链接大多在微信内置浏览器里打开，iOS 微信的 `clipboard` 时灵
  时不灵，所以兜底特意按 iOS 的 Range 选区写法实现（见 `static/app.js`
  的 `legacyCopy`）。

## 视觉

取向是：**高级感来自克制与质感，宿命感来自尺度对比**——人在浩大之中很小。
所以没有闪光、没有堆装饰，全站只有金与深蓝两个色系。

- **首屏是一枚宇宙尺度的太极**（纯 SVG，140 颗定种子星场）。三分钟转一圈，
  慢到察觉不到在动。立体感靠一条规矩：**材质随盘旋转，光不转**——
  `.taiji-spin` 里只放阴阳面与鱼眼，光照层和边缘光留在外面，光源恒定在左上。
  光要是跟着转，实体感立刻塌成一张贴纸。
- **金色压低彩度**。高饱和的正黄金最容易显廉价，换成香槟珠光才有金属质感；
  暗侧衰减也要克制，压过头金面会发灰，反倒像脏了。
- **鱼眼不能填反**。按太极路径的几何，`(100,55)` 落在阴面、`(100,145)` 落在
  阳面，所以前者是白点、后者是黑点。填反了两点各自与所在半面同色，
  「阴中有阳、阳中有阴」这层意思就没了——这是内容错误，不只是配色问题。
- **想换成生成图**（星云、古籍、窗前人影这类）：把 `.hero-art` 里的两个
  `<svg>` 换成 `<img>`，保留同样的绝对定位与遮罩即可，文字层不用动。
- **左侧压暗用遮罩而不是盖暗色矩形**。盖矩形在宽屏（`main` 窄于视口）时
  会露出一道竖直边；遮罩淡化图形本身，任何背景下都不留痕迹。
- **两色大标题**（一行金一行白）、**细金线加菱形收口**——参考同类产品里
  最抓眼、也最容易做砸的两处，关键在字重和留白，不在特效。

- **底色偏玄**（深蓝黑）配暖金强调。冷底衬暖光才有纵深，纯暖黑会发闷。
- **胶片颗粒**（`body::before`，4.5% 不透明度）。这一条是深色界面从「平」变
  「贵」的关键：纯色块看着像未完成的稿子。
- **十二地支环**缓慢自转，环心抬到视口之上，只让下缘的弧扫过画面。完整露出
  会变成图标，截取一段弧才是氛围。
- **排盘是仪式**：面板依次浮起，四柱逐柱落定。`static/app.js` 里的 `CAST_BEAT`
  是刻意加的推演停顿（850ms）——排盘本身几毫秒就算完，秒出结果反而像查表，
  折损可信度。嫌慢改成 `0` 即可恢复秒出。
- **五行用五角生克图**而非条形图：五行本就是一个五边形，外环相生、内星相克，
  这层关系条形图根本表达不了。节点用「大小 + 填充深浅」双重编码，缺某一行
  一眼看得出来。
- **平滑滚动带兜底**（`static/app.js` 的 `scrollToEl`）。微信内置浏览器里
  `behavior:'smooth'` 有时会静默失效、什么都不发生；主 CTA 不能因此变成
  死按钮，所以滚完校一次位，没到位就直接跳过去。

## 部署

⚠️ **这是一个 Python 服务，不是静态站点。** 任何「静态网站托管 / 对象存储 /
CDN 静态分发」类产品都跑不了它——那些只分发死文件，不会执行 `app.py`，
结果是首屏能显示，但排盘（`/api/chart`）和微信配置（`/api/config`）全部 404，
`index.html` 里的 `__V__` 占位符也不会被替换。必须选能跑容器或 Python 进程的产品。

| 平台 | 产品 | 备案 | 国内速度 |
|---|---|---|---|
| 腾讯云 CloudBase | **云托管**（不是静态网站托管） | 默认域名免备案 | 快 |
| 阿里云 / 腾讯云 | 轻量应用服务器 | 自有域名需备案 | 快 |
| Render / Railway | Web Service | 不需要 | 一般 |

带 `Dockerfile` 的平台（CloudBase 云托管等）直接识别，监听端口填 **80**。
不用 Docker 的平台（Render / Railway）走 `Procfile`：

```bash
uvicorn app:app --host 0.0.0.0 --port $PORT
```

静态资源的缓存已经处理好：`app.py` 会按 `style.css` / `app.js` 的修改时间生成
版本号注入到 `index.html` 的引用里，改完文件用户立刻拿到新版，不必手动改版本串，
也不用为此关掉缓存。

## 合规

- 页脚已声明命理属传统解释框架，不构成医疗/法律/投资建议。
- 微信小程序运营规范明确禁止算命占卜类内容，不建议走小程序；网页版没有
  这层限制。中国大陆境内部署需 ICP 备案。
- 引流到微信之后是真人对话，**边界要靠你自己把握**：不做医疗诊断、不荐具体
  投资标的、不预测死期、遇心理危机迹象转向求助建议。这既是伦理，也是降低
  纠纷风险。

## 已停用的模块

`bazi/ai.py`（Claude 问命内核）和 `payments.py`（Stripe 付费墙）**没有被
app.py 引用，不会产生任何费用**。保留是为了将来若要恢复自助付费，不必从头再写。

要恢复 AI 问命，需要：装 `anthropic`、设 `ANTHROPIC_API_KEY`、在 app.py 里
重新加回会话存储与额度控制。**注意那条路会带回一个真实漏洞**——排盘不需要
身份验证，循环排盘就能白嫖免费额度、烧掉你的 API 预算，届时必须先做限流。
