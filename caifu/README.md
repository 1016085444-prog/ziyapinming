# 子牙财鉴 · 财富指数测算站

「测一测」式的财富测算：输入生辰，八字与紫微斗数两张盘合参，给出财富指数、
财富五力、一生财运曲线、近三年财运与招财指南，末尾引导加微信做真人精批。

**与主站（子牙品命）是两个独立站点**：独立入口、独立页面、独立配置、独立
网址，互不链接。唯一共享的是排盘内核 `bazi/`、`ziwei/` 和两份通用前端脚本
（`static/common.js` 剪贴板兜底等、`static/places.js` 354 城市表）——这样两个
站对同一个生辰排出的盘永远一致，修一处两边同时生效。

## 跑起来

```bash
.venv/bin/uvicorn caifu.app:app --reload --port 8100
```

打开 http://127.0.0.1:8100 。测试与主站一起跑：

```bash
python3 -m unittest discover -s tests -v
```

## 上线前要改的

全在 [`config.py`](config.py)，也都能用环境变量覆盖（前缀 `CAIFU_`）：

| 项 | 说明 |
|---|---|
| `CAIFU_WECHAT_ID` | 微信号。默认与主站同一个，要分开接待就填另一个 |
| `CAIFU_WECHAT_OFFER` | 加微信能得到什么，要具体 |
| `CAIFU_PREMIUM_PRICE` | 精批价格，如 `¥99`。留空则不显示价格 |
| `caifu/static/wechat-qr.png` | 二维码图片，放了才显示 |

价格只写真实售价。**不要做「原价 ¥399 → 现价 ¥99」这种划线价**，除非那个
原价真实成交过——虚构原价属于价格欺诈，平台和市场监管都会查。

## 部署（独立服务）

用仓库根目录的 `Dockerfile.caifu`，构建上下文是仓库根：

```bash
docker build -f Dockerfile.caifu -t caifu .
```

腾讯云 CloudBase 云托管：**新建一个服务**（别和主站共用），Dockerfile 名称填
`Dockerfile.caifu`，端口 80。新服务会拿到自己的默认域名，或绑定你的独立域名。
不用 Docker 的平台，启动命令是：

```bash
uvicorn caifu.app:app --host 0.0.0.0 --port $PORT
```

## 分数怎么来的

| 输出 | 来源 |
|---|---|
| 财富五力 | 正财 / 偏财 / 守财 / 创富 / 贵人，八字十神·喜忌·财库 + 紫微财帛·田宅·官禄·四化，逐条写依据 |
| 财富指数 | 八字「财富机遇」35% + 紫微「财富机遇」35% + 五力均值 30%，归一到中位 68、散布 12 |
| 胜过 X% | 4000 张随机命盘的实测分布表（`calibration.py`），不是拍脑袋的数字 |
| 品阶 | 按位次分五品：前 5% 一品、5–20% 二品、20–45% 三品、45–75% 四品、其余五品 |
| 一生财运 | 每步八字大运的喜忌与财星/食伤，合参同期紫微大限化禄、化忌落宫 |
| 近三年 | 流年十神 + 流年五行喜忌 + 紫微流年四化落财帛/田宅/官禄 |

**改了 `report.py` 里任何权重，必须重跑校准**，否则「胜过 X%」就不准了：

```bash
.venv/bin/python tools/calibrate_caifu.py
```

`tests/test_caifu.py` 盯着分布有没有跑偏，忘了重跑会直接报错。

和主站同样的硬约束：分数夹在 38–96；每项必须给依据；低于 52 分必须附带
方向（`ADVICE`）；措辞不用「破财」「穷命」这类判词——测试都守着。

## 视觉

黑漆底 + 香槟/赤金箔 + 唯一一处朱砂印。贵气来自克制：金只用在发丝线、角花、
关键数字上，大面积仍是黑。首屏是一枚「招财进宝」方孔金钱（纯 SVG，光泽斜扫，
缓慢浮动），结果页第一屏是一张可截图分享的「财富金卡」——仿黑金信用卡，
带芯片与朱砂印，这是最主要的自传播载体。
