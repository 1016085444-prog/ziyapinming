# 腾讯云「云托管 / 微信云托管」零影响上线指南（一密一人卡密版）

> **核心原则**：在云托管里**新建一个独立服务**，拉取 GitHub 的 **`feat/card-codes` 分支**。
> 你原来的旧网站（和 `main` 分支）**一个字不动、完全隔离、零影响**！

---

## 第一步：在云托管里准备好 MySQL（防容器休眠丢密码，必做！）

腾讯云云托管的容器在闲置缩容或重启时会清空容器本地硬盘，所以一次性密码**必须存进数据库**（代码已内置自动识别云托管 MySQL，建库建表全自动，无需手动写 SQL）：

1. 打开腾讯云「云托管」或「微信云托管」控制台 → 左侧找到 **「数据库 / MySQL」**。
2. 若还没有数据库，点击 **开通 MySQL**（最低规格 Serverless/基础版即可，卡密表极轻）。
3. 记下连接信息里的 3 项（在数据库详情页可直接看到）：
   - **内网地址**（格式类似 `10.x.x.x:3306`）→ 填到下面的 `MYSQL_ADDRESS`
   - **用户名**（通常为 `root`）→ 填到 `MYSQL_USERNAME`
   - **密码** → 填到 `MYSQL_PASSWORD`

---

## 第二步：新建一个独立服务（完全不影响旧网站）

1. 在云托管控制台 → **「服务管理」→ 点击「新建服务」**（不要点旧服务的“发布新版本”！）。
2. 服务名称填一个新名字，例如：`ziyapinming-card`（平台会自动给它分配一个全新独立的 `.tcloudbase.com` 访问地址）。
3. **部署方式**：选 **「代码库 / GitHub」**：
   - 仓库选：`1016085444-prog/ziyapinming`
   - **分支务必选：`feat/card-codes`**（不要选 `main`）
   - 构建方式：`Dockerfile`（仓库根目录自带，端口 `80`）
4. **环境变量**（在“高级设置 / 环境变量”里添加以下 6 项）：

| 变量名 | 填写内容 | 说明 |
|---|---|---|
| `REQUIRE_CODE` | `1` | 开启一密一人核销（填 `0` 可临时关闭） |
| `WECHAT_ID` | `ziyapinming` | 网站底部与提示中的微信号 |
| `ADMIN_TOKEN` | `你自己设一个高强度口令` | 登录 `/admin` 发卡后台用，切勿外泄 |
| `MYSQL_ADDRESS` | `你的MySQL内网地址:3306` | 如 `10.12.34.56:3306` |
| `MYSQL_USERNAME` | `你的MySQL用户名` | 如 `root` |
| `MYSQL_PASSWORD` | `你的MySQL密码` | 数据库密码 |

   > 可选：`MYSQL_DATABASE` 默认自动建库 `ziyapinming`，如果想换库名可另填。
5. 点击 **「部署 / 发布」**，等待约 2–3 分钟构建完成。

---

## 第三步：验证持久化 & 开始批量发卡

发布成功后，云托管会给你一个**全新的独立公网域名**（例如 `https://ziyapinming-card-xxxx.sh.run.tcloudbase.com`）：

1. 打开 **`https://你的新域名/admin`**，输入刚才设置的 `ADMIN_TOKEN` 登录。
2. 看顶部状态条：确认显示绿色 **`✓ 持久化正常：云端 MySQL（云托管缩容/更新不丢密码）`**——看到这一行就彻底稳了！
3. 点击 **「一键生成」**（如一次生成 100 个，备注写 `小红书第1批`）→ 点击 **「下载本批 .txt」**。
4. 打开下载的 `.txt`（一行一个密码，格式 `ZY-XXXX-XXXX`），直接导入你的自动发货工具即可。
5. 自己拿一个测试密码打开 **`https://你的新域名/`** 填一个生日测一遍：
   - 正常出八字盘 → 点「换紫微斗数看这张盘」→ 同一密码自动带过去直接出紫微盘；
   - 再拿同一个密码换另一个生日测 → 应提示「此密码已绑定其他生辰，一个密码仅限排测一人」。
6. 测试完在 `/admin` 里点那个测试码的 **「停用」**，即可正式对外售卖。

---

## 附：如以后改用腾讯云轻量应用服务器 / CVM（单机版）
若是独立 Linux 服务器（且**没有**旧网站占用 80 端口），可使用同目录 `tencent-cloud.sh`；若服务器上已有旧网站，请用独立端口（如 `8010`）与独立二级域名 Nginx 配置，避免覆盖原有站点。
