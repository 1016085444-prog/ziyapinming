# 投研智能体

股票、基金、ETF、指数的分析软件。两层能力：

- **量化体检**（免费、几秒出结果、不用大模型）：K 线与指标、收益风险、估值与财务、
  基金经理与规模，汇总成六个维度的评分和五档评级，**每一分都列出依据**。
- **AI 多智能体深度分析**（需要一个大模型 API Key）：把开源项目
  [TradingAgents](https://github.com/TauricResearch/TradingAgents) 的投研团队搬过来——
  技术面、基本面、资讯三位分析师并行写报告 → 多头与空头研究员辩论 → 研究主管形成投资计划
  → 交易员给出入场、止损和仓位 → 激进、保守、中性三位风控辩论 → 投资经理拍板。
  每个智能体的发言在网页上实时滚动出来。
- **每日精选**（不用大模型也能跑）：收盘后先看「市场温度」（整个 A 股贵不贵）和「大盘预估分」（这几天适不适合出手），
  再分**短期、中期、长期、定投**四个板块选股票、ETF 和基金，没有合适的就空仓。每只入选的都写明持有多久、
  预期收益、什么时候卖、怎么止损；每个方法都在 2005–2026 年两个十年的真实行情上检验过，结果和最差的情况原样写出来。
  之后还会提醒之前入选的现在该卖还是该拿，并跟踪实际涨了多少。

覆盖 A 股（沪深京）、港股、美股、场内 ETF/LOF、场外公募基金、主要指数；
数据源覆盖不到的产品（银行理财、私募、自己记的净值）可以导入 CSV 分析。

> ⚠️ 仅供研究与学习参考，不构成投资建议。模型和数据都可能出错。

## 快速开始

需要 Python 3.10 或更高版本（3.10 – 3.14 都测试过，3.15 预览版也能跑）。

**Windows**：双击 `start.bat`。
**macOS**：双击 `start-mac.command`（被系统拦下时，到「系统设置 → 隐私与安全性」底部点「仍要打开」）；
或者在终端进入 `touyan` 文件夹，运行 `bash start.sh`。**Linux** 同样运行 `bash start.sh`。
macOS 自带的 python3 是 3.9，太旧；脚本会自动找已安装的新版本，找不到会提示去
[python.org](https://www.python.org/downloads/) 下载安装。

第一次会自动创建虚拟环境、安装依赖（优先走清华镜像，失败自动换官方源），之后秒开，
浏览器打开 http://127.0.0.1:8600 。

手动安装也可以：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

不配置大模型也能用全部量化功能。要用 AI 深度分析，打开「设置」，选一家服务商、粘贴
API Key、点「测试连接」。推荐 **DeepSeek**：国内直连、便宜；默认一次完整分析 11 次模型调用
（辩论轮数调到最大时 21 次），通常 2–8 分钟。

## 能做什么

### 量化体检

| 维度 | 看什么 |
|---|---|
| 趋势 | 均线排列、价格与 60 日线 / 年线的关系、MACD 所在区域 |
| 动量 | 20 / 60 日涨跌、MACD 与 KDJ 交叉、RSI、量价配合、布林带位置 |
| 风险 | 年化波动、最大回撤、贝塔、单日 VaR（分数越高风险越低） |
| 估值 | 动态市盈率、市净率、PEG |
| 质量 | ROE、毛利率、净利率、负债率、经营现金流 / 利润 |
| 成长 | 营收与净利润增速、扣非差异、增速加快还是放缓 |

基金换一套维度：**业绩**（相对基准、同类排名、三年年化）、**回撤控制**、**性价比**（夏普、卡玛）、
**稳定性**（经理任期、规模、持仓集中度）、趋势。ETF 和指数只看趋势、动量、风险（ETF 加规模）。

打分规则写死在代码里，口径刻意保守：

- 每个维度从中性 50 分起，按信号加减，夹在 5–95，**每一分都对应界面上的一条依据**。
- 缺数据的维度不参与加权，同时降低置信度——不拿 50 分冒充。
- 两处容易算错的口径专门处理了：A 股季报的 ROE 是累计值（一季报只有全年约 1/4），
  打分前先按报告期年化；银行、保险等金融企业不评负债率和毛利率。
- 估值只看绝对水平，**没有做同行业对比**，依据里会写明这一点。

指标口径对齐通达信 / 东方财富（MACD 柱 = 2×(DIF−DEA)、KDJ 9-3-3、RSI 用 Wilder 平滑），
开发时与 TradingAgents 用的 stockstats 逐值比对过。收益一律用复权价：股票取前复权，
基金用每日「净值回报」连乘出复权净值——直接拿单位净值算，分红会被算成亏损。

### AI 深度分析（TradingAgents 架构）

| 阶段 | 角色 | 产出 |
|---|---|---|
| ① 分析师团队（并行） | 技术分析师、基本面分析师（基金为基金研究员）、资讯分析师 | 三份报告 |
| ② 研究团队 | 多头研究员 ⇄ 空头研究员，辩论 1–3 轮 → 研究主管 | 投资计划与评级 |
| ③ 交易员 | 交易员 | 操作方向、入场价、止损价、目标价、仓位 |
| ④ 风控团队 | 激进型 → 保守型 → 中性，辩论 1–3 轮 | 风险审议 |
| ⑤ 决策 | 投资经理 | 最终五档评级、目标价、持有期、信心 |

和原项目相比的几处取舍：

- **分析师不走工具调用。** 程序先把数据取齐、算好，写成「核验数据简报」放进提示词，模型只负责解读，
  并被要求「引用具体数字时以简报为准、简报里没有的不要写」。国产模型的工具调用稳定性参差不齐，
  这样更稳、更省钱，也从根上避免了编造价格（原项目 #830 讨论过的问题）。
- **不依赖 LangGraph。** 编排是一段直白的 Python 流程，逐字推送到网页（SSE）。
  任务在后台跑，刷新页面或断网重连都不会中断。
- **保留了原项目踩坑后加上的规则**：「有分歧」不是持有的理由；对手还没发言时明确告诉模型
  先陈述己方观点（否则它会编一个对手论点来反驳）；价格必须写绝对值；读不出评级就记为
  「待复核」，绝不默认成「持有」；交易员给出的价位方向不对或离现价太远会被标注出来。
- **记忆与复盘**：每次结论都存档；投资经理分析同一标的时，会读到过往结论和之后的实际涨跌。

可以填上自己的持仓（数量、成本、可用资金），交易员和投资经理会给出针对这笔仓位的操作；
不填时会被明确告知「不知道用户持仓，不要假设空仓」。

### 每日精选（短期 / 中期 / 长期 / 定投）

点导航栏「每日精选」→「生成今日精选」。第一次要下载四千多只股票的日线，大约 5–10 分钟；同一个交易日里
再生成只要十几秒（下载好的数据存在数据目录的 `daily_pool.bin`）。不用大模型也能跑。

四个板块各用一套方法，都不用 MACD、KDJ、均线金叉这类通用指标。每条规则都放回 **2005–2026 年的真实行情**里
检验过，而且分两段各看一遍：近十年（2016.8–2026.11）是定方法时看着的；更早的十年（2005–2016.7）定方法时没用过，
算「没见过的十年」——两段都成立的规则才留下。检验口径尽量吃亏：信号收盘后才知道，所以第二天开盘买；
开盘就涨停的买不进；当天买的当天不能卖；封死跌停卖不掉就顺延；每笔扣 0.2%（指数基金 0.1%）；
股票池按当时成交活跃的股票算，包括后来退市的。财报按当时真正能看到的日期对齐，不提前用。

**市场温度（四个板块共用）。** 整个 A 股现在贵不贵：全市场活跃股票的中位数市净率、流通市值最大 300 只的
中位数市净率，各自在之前十年里排在什么位置，取平均。0 最便宜、100 最贵，只用当天之前的数据。
2008–2026 年在各档温度买入中证全指，之后两年的结果：

| 温度 | 之后两年平均 | 赚钱的比例 |
|---|---:|---:|
| 20 以下（很冷） | +46% | 100% |
| 20–40（偏冷） | +36% | 74% |
| 40–60（不冷不热） | +7% | 46% |
| 60–80（偏热） | −10% | 18% |
| 80 以上（很热） | −26% | 0% |

只按「低于 40 买入、高于 80 卖出」做中证全指，18 年半里换了 9 次仓，年化从一直拿着的 +1.5% 变成 +10.1%，
最大回撤从 60% 降到 35%；沪深300 是 +0.2% 对 +9.2%。这段历史里完整的冷热循环只有四五轮，次数不多，
但每一轮方向都一样。

| 板块 | 持有 | 什么时候出手 | 买什么 | 怎么卖 | 两个十年的检验（近十年 / 更早的十年） |
|---|---|---|---|---|---|
| **短期 · 看天出手** | 5 个交易日 | 大盘预估分 ≥3 才出手（约一成的日子），2 分轻仓；温度 80 以上不做 | 近期跌得多、没人追、公司在赚钱的 5 只；也可以直接买宽基 ETF | 第 5 个交易日收盘卖；收盘跌破买入价 8% 止损 | 每笔平均 +2.9% / +2.6%，61% 赚钱；同样的规则每天都用只有 +0.3% |
| **中期 · 冷门蓄势** | 1–6 个月 | 温度越低越好，80 以上不买 | 冷热分最冷的一成、不是大盘股、在赚钱且利润增长 10% 以上 | 变热了（冷热分掉到 30 以下）就卖；收盘涨停的第二天卖；最多 120 个交易日 | 每笔平均 +4.1% / +9.7%，60% / 69% 赚钱；温度 40 以下买入是 +7.5% / +9.2% |
| **长期 · 低温买入** | 2–3 年 | 温度 40 以下才买，60 以上不新买，80 以上分批卖 | 稳健名单里股息率高的至少 8 只，或者直接买指数基金 | 温度到 80 以上分批卖；每季度复查，不在名单里了就换 | 温度 40 以下买入整个名单、拿两年：平均 +42% / +72%，95% / 100% 的时候赚钱 |
| **定投 · 看温度定投** | 3 年以上，每月一次 | 每月都投；境内宽基按温度决定投几倍 | 宽基、红利、美股指数基金 | 宽基温度 80 以上全部卖出、回到 40 以下分 12 个月投回；红利和美股一直不卖 | 每只基金用自己的净值模拟：宽基年化从 3%–7% 提到 9%–12% |

**短期 · 看天出手。** 短线的输赢主要取决于哪天出手，而不是挑哪只：同一套选股规则，只在「大盘预估分」高的
日子用才赚钱，每天都用平均每笔只有 +0.3%、一半亏钱。大盘预估分在收盘后打：全市场放量、当天大涨或大跌、
涨停或跌停很多、5 天跌了不少，各加分（大面积跌停后最强，加 2 分）；涨跌不到 0.5% 的平淡日、缩量日各扣 1 分；
明天是月末最后一天或月初第一天、明天是周一加分，明天是周四扣分。分数 ≥3 的日子之后 5 天全市场平均 +1.6%，
≤−1 的日子平均 −0.5%。分数够了再看风格（小盘近期领涨、市场活跃时偏中小盘，市场冷清时偏大盘）和板块
（当天涨停最集中的板块不碰，这类板块之后平均跑输），最后选股：近 5 天、近 20 天跌得多、离一年高点远、
冷热分偏冷，当天没涨停跌停、没涨 5% 以上，公司在赚钱。第二天开盘买（高开 2% 以上放弃），拿 5 个交易日，
收盘跌破买入价 8% 止损，不设止盈。按市场温度分开看：温度 40 以下出手平均 +3.8% / +4.0%，
60 以上只有 +0.8% / +1.6%，80 以上（近十年只有几天，主要看更早的十年）是 −1.1%，所以温度 80 以上不出手、60 以上减半。
最差的年份：2026 年（近十年）、2005 年（更早的十年）是亏的。

**中期 · 冷门蓄势。** 被追捧的股票之后跑输，没人理的股票之后跑赢。「冷热分」量的是一只股票有没有人在追：
近 60 天盘中有没有被拉升、近 20 天成交有没有放大、是不是越涨越放量、是不是天天收在高位，四项在全市场排名次，
0 最热、100 最冷。二十二年里最热的一成没有一年跑赢过随便买。入选条件：冷热分在最冷的一成、流通市值不在
全市场最大的三成（这个规律在大盘股里基本不成立）、公司在赚钱且最新财报净利润同比增长 10% 以上、
当天没有涨停跌停、同一行业大类最多两只。第二天开盘买（高开 3% 以上放弃），买了就拿着，直到它变热：
冷热分掉到 30 以下就卖，收盘涨停的第二天开盘卖，最多拿 120 个交易日（平均拿 50–65 天）。
不设价格止损——检验过 12% 的止损，近十年每笔平均从 +4.1% 掉到 +1.4%。买入时机看温度：40 以下买入每笔平均
+7.5%、67% 赚钱（近十年）/ +9.2%、71%（更早的十年），80 以上买入是 −2.2% / −2.9%。
亏钱的年份：2017、2018、2023、2026 年（近十年），2011 年（更早的十年）。

**长期 · 低温买入。** 长期的结果主要取决于买的时候市场贵不贵，买什么反而是其次。温度 40 以下买、40–60 少买慢买、
60 以上不新买、80 以上分批卖出。买的东西从「稳健名单」里挑：公司在赚钱；近一年有现金分红；近三年年报 ROE
没有低于 8% 的；最新财报净利润同比没有掉 20% 以上（防高股息陷阱）；去掉「四种热」——一年波动最大的两成、
换手最高的两成、冷热分最低的两成、两年半涨得最多的两成；去掉「长期走弱」的行业（两年半的表现排在后三成、
最近半年也在后一半）。按股息率从高到低排，同一行业大类最多两只，至少分散买 8 只；不想选股就直接买宽基或
红利指数基金，同样看温度。稳健名单每月更新、连续持有，年化 +9.2%（近十年，全部股票是 +1.5%）/
+27.3%（更早的十年，全部是 +20.4%）。最差的情况：温度 40 以下买入名单整体、拿两年，最差一次是 −5%（近十年）。

**定投 · 看温度定投。** 定投的关键不在怎么买，在会不会卖。候选是沪深300、中证500、中证1000、创业板、科创50、
上证50、中证红利、红利低波、恒生、恒生科技、纳斯达克100、标普500 的指数基金（A 类份额，选成立最早的那只，
至少 5 年净值）。境内宽基：温度 20 以下投 2 倍、20–40 投 1.5 倍、40–60 正常、60–80 减半、80 以上停投并全部卖出，
卖出的钱等温度回到 40 以下分 12 个月投回去。每只基金都用它自己十几年的真实净值模拟：一直定投不卖，
年化只有 3%–7%；按温度卖出、再投回，年化 9%–12%（比如沪深300 从 3.8% 到 8.9%、中证500 从 4.0% 到 9.8%）。
红利类和美股指数基金正相反，一直投、不卖最好（加了止盈反而少赚）。「赚 20%/30% 就卖」的目标止盈法在各类基金上
都没有稳定的好处。定投日放在每月 26 号以后：月末那几天的收盘价平均比当月均价低 0.25%–0.5%。
历史上定投年化不到 3% 的基金不推荐（比如恒生科技、恒生指数），排名表里能看到。

**行业：冷了很久的会不会补涨？** 检验过（申万二级行业，2010–2026 年）：连续跑输 4 年以上的行业，之后两年
比全部行业平均少涨 7.8%、三年少涨 10.4%；前两年涨得多、最近半年还强的行业，之后两年多涨 5.6%（15 年里 10 年如此）。
同一时间比行业，冷了很久的并不会补涨，强的继续强。行业自己估值很低的时候买确实赚得多，但那份好处主要来自
「整个市场都便宜」——也就是市场温度。所以长期板块去掉长期走弱的行业、买入时机看温度；中期、短期按行业分开看没有差别。

**之前入选的，现在该怎么办。** 每次生成时，把最近几次短期、中期板块入选的股票按各自的卖出规则重新对一遍：
到期、止损、变热了、涨停了的写「该卖了」，还在拿的写「继续拿」以及离止损还有多远，停牌或取不到行情的写出来让你自己查。

**历史表现。** 每次结果都存档。页面上点「计算历史表现」：按入选后第二个交易日买入（股票、ETF 用开盘价，
基金用当天净值），统计短期第 3 / 8 天、中期第 20 / 120 天、长期和定投第 60 / 250 天以及至今的平均收益、胜率、
相对沪深300 的超额。这是方法定下来之后才发生的行情，比任何回头检验都更有说服力；样本少于 30 个只能看个大概。

**一律按收盘算。** 交易日 9:15–15:00 之间生成，用的是上一个交易日的收盘——K 线去掉今天还没走完的那根；
全市场数据优先用上次收盘后自动存下的那份，没有的话用实时行情倒推到昨收。上一个交易日已经有结果时直接显示它。
页面顶部写明数据是「今天收盘」「上一个交易日收盘」还是「不是今天的数据」。勾选「交易日收盘后自动生成」后，
软件开着的话每个交易日 15:45 之后自动跑一次；也可以用命令行配合系统定时任务：

```bash
.venv/bin/python cli.py daily --md 精选.md
```

**研究底稿。** 检验用的脚本和结果都在 `research/`（不在分享包里）：`exp*.py` 是一个个实验，`results/` 是它们的输出，
`gen_evidence.py` 把结论汇总成 `daily/evidence_data.py`，页面和文字版里的历史数字都从这里来。重新检验需要
numpy 和 pandas，以及自己下载的历史数据。

**需要知道的局限。**

- 22 年、两个十年，只包含四五轮完整的牛熊。规律在过去成立，不代表以后一定成立；每一笔都可能亏。
- 统计都是「一篮子」的平均：短期按 5 只、长期按整个名单算。只买其中一两只，结果会分散得多。
- 短期在 2026 年是亏的（近十年里唯一亏的一年）。方法的优势是「很多次加起来」的，单独一次可能很难看：
  一篮子 5 只在 5 天里最多亏过 15%（近十年）/ 23%（2015 年）；中期每 20 笔里就有 1 笔亏 29% 以上。
- 市场温度用的是市净率，银行、地产这类公司的估值长期偏低，会让温度整体偏冷一点；它说的是「整个市场」，
  对单只股票、港股和美股不适用。
- 一个板块生成失败不会影响其他板块，原因会写在页面底部的「数据提示」里。
- 这些方法是本项目自己设计、自己检验的，没有哪个是「必赚」的。请把「方法体检」和「历史表现」两处的数字当作判断依据。

**思路来源。** 管线和产品形态学自 [daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)
（全市场快照 → 筛选 → 把结论写成可执行的计划）；方法参考的是公开的研究结论：估值水平对之后几年收益的预测力
（Campbell、Shiller 1988）、短期反转是给流动性提供者的补偿（Campbell、Grossman、Wang 1993；Nagel 2012）、
A 股 T+1 下隔夜与日内收益的差异（Qiao、Dam 2020）、A 股里异常换手代表的情绪（Liu、Stambaugh、Yuan 2019）、
行业动量（Moskowitz、Grinblatt 1999）。具体的规则、阈值都是在这里的数据上重新检验出来的。

### 其他

- **多品种对比**：最多 6 个，股票、基金、指数可混合。同一纵轴的累计收益（起点归一为 0%，
  不做双纵轴）、关键指标、日收益相关系数（只用双方都交易的日子）。
- **历史与复盘**：每次深度分析的结论 + 之后的实际收益与同期超额收益，统计方向正确率。
  口径：分析当日收盘买入，持有到最新收盘，在同一条复权序列里取价。
- **导入 CSV**：只要「日期」和「收盘价/净值」两列，中英文表头、UTF-8/GBK 都认。
- **导出**：量化报告和 AI 报告都能下载 Markdown，或直接打印 / 另存 PDF。
- **命令行**：

```bash
.venv/bin/python cli.py analyze 600519            # 量化体检
.venv/bin/python cli.py analyze 110011 --deep     # AI 深度分析，终端实时输出
.venv/bin/python cli.py search 茅台
.venv/bin/python cli.py doctor                    # 自检：数据源与大模型配置
.venv/bin/python cli.py daily                     # 生成每日精选
```

| 财报：利润、ROE、行业（每日精选） | 东方财富数据中心 | — |

这些都是网页在用的公开接口，**没有官方文档，随时可能变**。接口地址、参数和字段含义参照
akshare（2026-11 版）的实现；字段含义没有经过它印证的一律不用。

几条保护措施：

- **东方财富 push2 限流熔断。** 它对密集请求会直接断开连接、封 IP 几分钟到几十分钟，此时重试只会
  延长封禁。程序识别到后会在 6 分钟内自动改走腾讯等备用源；基准指数本来就优先走腾讯，分散压力。
- **缓存 + 旧数据兜底。** 行情缓存 15 分钟；所有数据源都失败时，用最近一次缓存并明确标注
  「X 小时前的缓存」。
- **辅助数据取不到不影响主流程**，页面上会列出缺了什么，智能体也会被告知「本次没有新闻」，
  而不是拿空白当作「没有利空」。
- 网络环境千差万别：**「设置 → 数据源自检」**（或 `cli.py doctor`）逐个探测每个数据源，
  哪个通、哪个不通一目了然。

## 分享给别人

```bash
cd touyan
python3 make_package.py        # 生成 dist/touyan-日期.zip，约 400 KB
```

把这个 ZIP 用微信、网盘发给对方即可。对方解压后 Windows 双击 `start.bat`、Mac 双击
`start-mac.command`；包里附了一份写给对方看的 `使用说明.txt`（装 Python、系统拦截怎么放行、
怎么填 Key、怎么更新）。每个人在自己的「设置」里填自己的 API Key，模型费用各付各的。
文件夹要放在不会同步到云盘的位置（Mac 的个人文件夹、Windows 的 C:\touyan 之类），放进 iCloud / OneDrive 同步的桌面或文稿里，几百 MB 的依赖和数据库会被反复同步，可能导致打不开。

**不要把自己电脑上的 `touyan` 文件夹直接压缩发出去**：`.venv/` 是本机装的依赖，几百 MB，换一台电脑也用不了；
1.1 及更早的版本还把 API Key 存在文件夹里的 `data/settings.json`，发出去别人就能用你的额度。
打包脚本只收运行需要的文件（不含 `data/`、`.venv/`、测试、Dockerfile），`tests/test_package.py`
会检查这一点。

对方更新到新版本：解压新包，直接从新文件夹启动，旧文件夹删掉即可（把旧文件夹整个替换掉也行）。
设置、API Key 和历史记录不在程序文件夹里（见下面「数据存在哪」），换版本不用重新填。
启动脚本按内容比对 `requirements.txt`，依赖有变化会自动补装，直接覆盖旧文件也没问题。

### 数据存在哪

设置（含 API Key）、历史记录、每日精选的存档和行情缓存，都放在**个人文件夹下的 `.touyan`**
（Mac：`/Users/你的用户名/.touyan`；Windows：`C:\Users\你的用户名\.touyan`），启动时终端里会打印这个位置，
「设置」页里也写着。程序文件夹里只有程序本身：换新版本、换位置、整个替换掉，设置都还在。

1.1 及更早的版本把这些存在程序文件夹的 `data/` 里，于是换一个新解压的文件夹、或者把文件夹整个替换，
API Key 就丢了；放在 iCloud / OneDrive 同步的目录里还可能读不出来。升级后第一次启动时，
程序会把所在文件夹里的 `data/` 自动搬到新位置（新位置已有内容的文件不会被覆盖）。
要放到别处，设置环境变量 `TOUYAN_DATA_DIR`（Docker 镜像里是 `/data`）。

另外两处保护：设置文件一时读不出来时不会用默认值把它覆盖掉（保存会被拒绝并提示稍后再试）；
在原文件夹里覆盖更新后，如果更新前启动的旧程序还开着，新程序会自动换一个端口启动并提醒关掉旧窗口，
不会再把人带到旧版本的页面上。

想让别人不用安装、打开网址就能用，见下一节：那样模型费用走你的 Key，务必设置访问密码；
如果要收费，先看文末「合规」一条。

## 部署到服务器

服务器上**务必设置访问密码** `APP_PASSWORD`。没设置时，深度分析和修改设置只允许本机访问——
大模型按调用计费，暴露到公网就会被别人刷光额度（原站 README 里提到的那个漏洞）。
设置后浏览器会弹出登录框，用户名随意，密码填 `APP_PASSWORD`。

Docker（构建目录选 `touyan/`）：

```bash
docker build -t touyan ./touyan
docker run -d -p 8600:8600 -v touyan-data:/data \
  -e APP_PASSWORD=换成你的密码 -e DEEPSEEK_API_KEY=sk-xxx touyan
```

**腾讯云 CloudBase 云托管**：新建一个服务（和八字站分开），代码目录选 `touyan`，它会识别这里的
Dockerfile；环境变量里加 `PORT=80`（云托管默认监听 80）、`APP_PASSWORD`、大模型 Key。
和原站一样，跑不了「静态网站托管」。

所有可配置项见 `.env.example`。

## 局限与风险（请读）

- **量化体检的评分规则没有经过回测验证**，只是把常见的分析框架写成了明确、可检查的规则（每日精选的方法是检验过的，见上面）。
  它告诉你「当前数据呈现什么特征」，不预测涨跌。
- **大模型会出错**：误读数据、过度自信、前后矛盾都可能发生。提示词要求它只引用核验过的数字，
  能减少但不能杜绝编造。
- 数据来自非官方接口，可能延迟、缺失或出错；盘中数据未收盘。
- 历史复盘的样本少时没有统计意义，短期结果受偶然因素影响很大。
- **合规**：在中国大陆，向不特定公众提供证券投资建议（尤其是收费荐股）需要证券投资咨询业务资格。
  本工具适合个人研究使用；**把每日精选的结果收费推送给别人，就属于荐股**。如果要对外提供服务，请先确认合规要求。
