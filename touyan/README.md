# 投研智能体

股票、基金、ETF、指数的分析软件。两层能力：

- **量化体检**（免费、几秒出结果、不用大模型）：K 线与指标、收益风险、估值与财务、
  基金经理与规模，汇总成六个维度的评分和五档评级，**每一分都列出依据**。
- **AI 多智能体深度分析**（需要一个大模型 API Key）：把开源项目
  [TradingAgents](https://github.com/TauricResearch/TradingAgents) 的投研团队搬过来——
  技术面、基本面、资讯三位分析师并行写报告 → 多头与空头研究员辩论 → 研究主管形成投资计划
  → 交易员给出入场、止损和仓位 → 激进、保守、中性三位风控辩论 → 投资经理拍板。
  每个智能体的发言在网页上实时滚动出来。
- **每日精选**（不用大模型也能跑）：收盘后扫一遍全市场，分**短期、中期、长期、定投**四个板块，
  各用一套自己设计的方法选股票、ETF 和基金。每只入选的都写明持有多久、预期收益、什么时候卖；
  每个方法都先拿历史数据检验自己，检验没过会直接写「没通过」。之后还会跟踪每天选出来的标的实际涨了多少。

覆盖 A 股（沪深京）、港股、美股、场内 ETF/LOF、场外公募基金、主要指数；
数据源覆盖不到的产品（银行理财、私募、自己记的净值）可以导入 CSV 分析。

> ⚠️ 仅供研究与学习参考，不构成投资建议。模型和数据都可能出错。

## 快速开始

需要 Python 3.10 或更高版本（3.10 – 3.14 都测试过，3.15 预览版也能跑）。

**Windows**：双击 `start.bat`。
**macOS**：双击 `start-mac.command`（被系统拦下时，到「系统设置 → 隐私与安全性」底部点「仍要打开」）；
或者在终端进入 `touyan` 文件夹，运行 `bash start.sh`。**Linux** 同样运行 `bash start.sh`。
macOS 自带的 python3 是 3.9，太旧；脚本会自动找已安装的新版本，找不到会提示去
[python.org](https://www.python.org/downloads/) 下载安装。

第一次会自动创建虚拟环境、安装依赖（优先走清华镜像，失败自动换官方源），之后秒开，
浏览器打开 http://127.0.0.1:8600 。

手动安装也可以：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

不配置大模型也能用全部量化功能。要用 AI 深度分析，打开「设置」，选一家服务商、粘贴
API Key、点「测试连接」。推荐 **DeepSeek**：国内直连、便宜；默认一次完整分析 11 次模型调用
（辩论轮数调到最大时 21 次），通常 2–8 分钟。

## 能做什么

### 量化体检

| 维度 | 看什么 |
|---|---|
| 趋势 | 均线排列、价格与 60 日线 / 年线的关系、MACD 所在区域 |
| 动量 | 20 / 60 日涨跌、MACD 与 KDJ 交叉、RSI、量价配合、布林带位置 |
| 风险 | 年化波动、最大回撤、贝塔、单日 VaR（分数越高风险越低） |
| 估值 | 动态市盈率、市净率、PEG |
| 质量 | ROE、毛利率、净利率、负债率、经营现金流 / 利润 |
| 成长 | 营收与净利润增速、扣非差异、增速加快还是放缓 |

基金换一套维度：**业绩**（相对基准、同类排名、三年年化）、**回撤控制**、**性价比**（夏普、卡玛）、
**稳定性**（经理任期、规模、持仓集中度）、趋势。ETF 和指数只看趋势、动量、风险（ETF 加规模）。

打分规则写死在代码里，口径刻意保守：

- 每个维度从中性 50 分起，按信号加减，夹在 5–95，**每一分都对应界面上的一条依据**。
- 缺数据的维度不参与加权，同时降低置信度——不拿 50 分冒充。
- 两处容易算错的口径专门处理了：A 股季报的 ROE 是累计值（一季报只有全年约 1/4），
  打分前先按报告期年化；银行、保险等金融企业不评负债率和毛利率。
- 估值只看绝对水平，**没有做同行业对比**，依据里会写明这一点。

指标口径对齐通达信 / 东方财富（MACD 柱 = 2×(DIF−DEA)、KDJ 9-3-3、RSI 用 Wilder 平滑），
开发时与 TradingAgents 用的 stockstats 逐值比对过。收益一律用复权价：股票取前复权，
基金用每日「净值回报」连乘出复权净值——直接拿单位净值算，分红会被算成亏损。

### AI 深度分析（TradingAgents 架构）

| 阶段 | 角色 | 产出 |
|---|---|---|
| ① 分析师团队（并行） | 技术分析师、基本面分析师（基金为基金研究员）、资讯分析师 | 三份报告 |
| ② 研究团队 | 多头研究员 ⇄ 空头研究员，辩论 1–3 轮 → 研究主管 | 投资计划与评级 |
| ③ 交易员 | 交易员 | 操作方向、入场价、止损价、目标价、仓位 |
| ④ 风控团队 | 激进型 → 保守型 → 中性，辩论 1–3 轮 | 风险审议 |
| ⑤ 决策 | 投资经理 | 最终五档评级、目标价、持有期、信心 |

和原项目相比的几处取舍：

- **分析师不走工具调用。** 程序先把数据取齐、算好，写成「核验数据简报」放进提示词，模型只负责解读，
  并被要求「引用具体数字时以简报为准、简报里没有的不要写」。国产模型的工具调用稳定性参差不齐，
  这样更稳、更省钱，也从根上避免了编造价格（原项目 #830 讨论过的问题）。
- **不依赖 LangGraph。** 编排是一段直白的 Python 流程，逐字推送到网页（SSE）。
  任务在后台跑，刷新页面或断网重连都不会中断。
- **保留了原项目踩坑后加上的规则**：「有分歧」不是持有的理由；对手还没发言时明确告诉模型
  先陈述己方观点（否则它会编一个对手论点来反驳）；价格必须写绝对值；读不出评级就记为
  「待复核」，绝不默认成「持有」；交易员给出的价位方向不对或离现价太远会被标注出来。
- **记忆与复盘**：每次结论都存档；投资经理分析同一标的时，会读到过往结论和之后的实际涨跌。

可以填上自己的持仓（数量、成本、可用资金），交易员和投资经理会给出针对这笔仓位的操作；
不填时会被明确告知「不知道用户持仓，不要假设空仓」。

### 每日精选（短期 / 中期 / 长期 / 定投）

点导航栏「每日精选」→「生成今日精选」，约 3–5 分钟（要下载几百只股票的日线；同一个交易日里重新生成
会直接用已下载的数据）。四个板块各用一套方法，都不用 MACD、KDJ、均线金叉这类通用指标——
每个方法先回答「对手盘是谁、凭什么能赚到这份钱」，再把规则放回历史行情里检验，把结果原样写出来。

| 板块 | 持有 | 从哪里选 | 赚谁的钱 | 预期收益从哪来 | 怎么止损 |
|---|---|---|---|---|---|
| **短期 · 错杀反弹** | 3–8 个交易日 | 核心池（市值最大的 300 只股票） | 急着卖的人：止损盘、被动减仓 | 同一规则在核心池过去一年半的模拟结果 | 收盘跌破止损价（这轮跌幅的四分之三，4%–8%） |
| **中期 · 悄悄走强** | 1–3 个月 | 核心池 + 20 只 ETF | 还没注意到它的人 | 同上（ETF 用三年行情） | 跟踪止损（6%–12%）+「热了就走」 |
| **长期 · 耐心溢价** | 1–3 年 | 全市场大中盘股 + 主动偏股基金 | 没有耐心的人 | 按财报推算：股息 + 留存利润带来的增长 | 不设价格止损，看基本面条件 |
| **定投 · 模拟出来的定投** | 3 年以上，每月一次 | 12 个指数的指数基金 | 自己的情绪 | 每只基金自己十几年净值的定投模拟 | 不止损；温度决定每月投多少；有止盈线 |

**短期 · 错杀反弹。** 止损盘和被动减仓的人不在乎价格，会把股价压到合理水平以下，等他们卖完价格会回来一段。
难点是分清「被砸下来的」和「真出事了的」，日线上的线索是：坏消息多在收盘后公布、第二天直接低开，
被动抛售则是盘中一路卖下来。所以把最近 5 天的跌幅拆成「隔夜跳空」和「盘中下跌」两部分。入选条件：
5 天跌幅 ≥ 4% 且是它自己平时 5 天波动的 1.6 倍以上；跌幅的六成以上是盘中跌出来的、没有 3% 以上的低开；
近 10 天没有涨停或跌停；近半年跌幅不超过 15%；公司在盈利。计划：第二天开盘买（高开 2% 以上放弃），
涨回这轮跌幅的一半止盈，再跌掉跌幅的四分之三止损，最多拿 8 个交易日。

**中期 · 悄悄走强。** 好消息是被一批批资金慢慢发现的，没人注意的股票会不声不响地沿一条斜线上行；
等它涨停、放巨量、上热搜，后知后觉的人来了，行情也差不多了。直接量四件事：涨得稳不稳
（近 60 日走势对一条直线的拟合度 ≥ 0.6、上涨天数 ≥ 53%）、强不强（涨 ≥ 8% 且比沪深300 多 5 个点）、
冷不冷（60 天内没有涨停、没有单日涨 7% 以上、成交量没有放大）、有没有业绩撑着（最新财报扣非净利润同比为正，
下滑的直接剔除）。计划：跟踪止损（从买入后的最高收盘价回落「它一周正常波动的 2.6 倍」，夹在 6%–12%），
赚了一成以上又出现涨停或 3 倍放量就卖给后来者，最多拿 60 个交易日。ETF 用同一把尺子、门槛放宽，一只都不合格就不硬选。

**长期 · 耐心溢价。** 多数资金按季度考核，对「三年后大概率更值钱、下个月不知道」的公司出价偏低。
不看 K 线，只看：近三年年报 ROE 最低 ≥ 8%、平均 ≥ 12%（金融企业 7% / 9%）；经营现金流不低于净利润的六成、
负债率不超过 70%（金融企业不看这两项）；最新一期利润没有下滑超过 10%。预期年化 = 股息率 + 留存利润带来的增长：
分红比例不另找数据，用「每股净资产一年的增加额 ÷ 每股收益」反推（送转、增发的年份不用），增长按
ROE ×（1 − 分红比例）封顶 12% 再打七折，并给出悲观、乐观两个情形。卖出看基本面：连续两期扣非利润下滑、
ROE 跌破门槛、现金流连续两年不到利润的一半，或者涨到市盈率过高。基金另用一把尺子：
大盘上涨的月份跟上多少、下跌的月份跌了多少。

**定投 · 模拟出来的定投。** 定投靠的是「跌的时候同样的钱买到更多份额」。候选是沪深300、中证500、中证1000、
创业板、科创50、上证50、中证红利、红利低波、恒生、恒生科技、纳斯达克100、标普500 的指数基金
（从天天基金排行里按名字找 A 类份额，取成立最早的那只，至少 5 年净值）。两件事都用它自己的真实净值算：
① 历史上任意一个月开始、每月投一次、投满 3 年的结果分布（赚钱概率、中位收益、较差的一成）——这就是预期收益；
② 温度：现在的净值 ÷「过去三年每月定投的平均成本」，在它自己历史上的排位（0 最便宜、100 最贵，只用当天之前的数据）。
温度低于 20 投 2 倍、20–40 投 1.5 倍、40–60 正常、60–80 减半、80 以上不买；按温度调倍数在这只基金的历史上
比普通定投好多少，也算出来写在旁边，没帮助就直说。

**核心池与方法体检。** 短期、中期两个板块在「市值最大的 300 只可交易股票」里选，并且只在这个池子里检验方法——
只拿今天的候选回头检验，结果必然好看（它们正是因为过去走得好才入选的）。体检按吃亏的口径模拟：
信号在收盘后才知道，所以买在**第二天开盘**；A 股当天买的当天不能卖，买入当天不检查卖出；止盈是挂单、
止损看收盘；每笔扣 0.2% 成本；一笔没卖出前同一只股票不重复算。结果和「同一批股票随便哪天买、拿同样久」对照，
多出来的才算方法的功劳；还会单独给出当前市场环境（按沪深300 走势分偏强 / 震荡 / 偏弱）下的统计。
样本少于 40 次写「样本不足」；中位数不为正或不比随便买好，写「没通过」，入选的只标为观察。
每只股票页面上的「预期收益」就是这份统计，不是预测。

**历史表现。** 每次结果都存档。页面上点「计算历史表现」：按入选后第二个交易日买入（股票、ETF 用开盘价，
基金用当天净值），统计短期第 3 / 8 天、中期第 20 / 60 天、长期和定投第 60 / 250 天以及至今的平均收益、胜率、
相对沪深300 的超额。这是方法定下来之后才发生的行情，比任何回头检验都更有说服力；样本少于 30 个只能看个大概。

**一律按收盘算。** 交易日 9:15–15:00 之间生成，用的是上一个交易日的收盘——K 线去掉今天还没走完的那根；
全市场数据优先用上次收盘后自动存下的那份，没有的话用实时行情倒推到昨收。上一个交易日已经有结果时直接显示它。
页面顶部写明数据是「今天收盘」「上一个交易日收盘」还是「不是今天的数据」。勾选「交易日收盘后自动生成」后，
软件开着的话每个交易日 15:45 之后自动跑一次；也可以用命令行配合系统定时任务：

```bash
.venv/bin/python cli.py daily --md 精选.md
```

**需要知道的局限。**

- 体检用的是现在市值最大的 300 只股票过去一年半的行情：时间短、只覆盖一种市场阶段，
  而且今天的大市值股票本身就是过去的赢家（幸存者偏差）。「随便买」对照能扣掉一部分，扣不干净。
- 长期板块的预期年化是按财报推算的估计，假设公司继续像过去几年那样经营，不含估值涨跌。
- 定投模拟用的是过去十几年的净值，包含几轮牛熊，但以后不一定重复。
- 一个板块生成失败不会影响其他板块，原因会写在页面底部的「数据提示」里。
- 这些方法是本项目自己设计的，没有哪个是「必赚」的。请把「方法体检」和「历史表现」两处的数字当作判断依据，
  体检没通过的板块不要照着买。

**思路来源。** 管线和产品形态学自 [daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)
（全市场快照 → 筛选 → 把结论写成可执行的计划、行业分散）；方法本身参考的是公开的研究结论而不是现成的指标：
短期反转是给流动性提供者的补偿（Campbell、Grossman、Wang 1993；Nagel 2012），A 股 T+1 下日内与隔夜收益的差异
（Qiao、Dam 2020 等），连续的小消息比抓眼球的大消息更容易被低估（Da、Gurun、Warachka 2014），
A 股里异常换手率代表的情绪（Liu、Stambaugh、Yuan 2019），以及把股票长期回报拆成股息、增长、估值变化（Bogle）。
具体的规则、阈值和检验方式都是这里重新设计的，所以更需要上面两处的数字来验证。

### 其他

- **多品种对比**：最多 6 个，股票、基金、指数可混合。同一纵轴的累计收益（起点归一为 0%，
  不做双纵轴）、关键指标、日收益相关系数（只用双方都交易的日子）。
- **历史与复盘**：每次深度分析的结论 + 之后的实际收益与同期超额收益，统计方向正确率。
  口径：分析当日收盘买入，持有到最新收盘，在同一条复权序列里取价。
- **导入 CSV**：只要「日期」和「收盘价/净值」两列，中英文表头、UTF-8/GBK 都认。
- **导出**：量化报告和 AI 报告都能下载 Markdown，或直接打印 / 另存 PDF。
- **命令行**：


## 数据从哪来

| 数据 | 首选 | 备用 |
|---|---|---|
| K 线 | 东方财富 | 腾讯证券（A 股、港股）→ akshare → yfinance（这两个需另装） |
| 基准指数 | 腾讯证券 | 东方财富 |
| 行情快照与估值 | 东方财富 | 腾讯证券 |
| 财务指标 | 东方财富数据中心（A 股、港股、美股） | — |
| 基金净值、规模、经理、持仓 | 天天基金 | — |
| 基金类型、基金公司、业绩基准 | 蛋卷基金 | — |
| 个股新闻 / 市场快讯 | 东方财富 | 新浪财经 7x24 |
| 全市场快照（每日精选） | 东方财富数据中心 | 东方财富行情 → 新浪行情中心 |
| 行业板块涨跌（每日精选） | 东方财富 | — |
| 开放式基金排行（每日精选） | 天天基金 | — |

这些都是网页在用的公开接口，**没有官方文档，随时可能变**。接口地址、参数和字段含义参照
akshare（2026-11 版）的实现；字段含义没有经过它印证的一律不用。

几条保护措施：

- **东方财富 push2 限流熔断。** 它对密集请求会直接断开连接、封 IP 几分钟到几十分钟，此时重试只会
  延长封禁。程序识别到后会在 6 分钟内自动改走腾讯等备用源；基准指数本来就优先走腾讯，分散压力。
- **缓存 + 旧数据兜底。** 行情缓存 15 分钟；所有数据源都失败时，用最近一次缓存并明确标注
  「X 小时前的缓存」。
- **辅助数据取不到不影响主流程**，页面上会列出缺了什么，智能体也会被告知「本次没有新闻」，
  而不是拿空白当作「没有利空」。
- 网络环境千差万别：**「设置 → 数据源自检」**（或 `cli.py doctor`）逐个探测每个数据源，
  哪个通、哪个不通一目了然。

## 分享给别人

```bash
cd touyan
python3 make_package.py        # 生成 dist/touyan-日期.zip，约 170 KB
```

把这个 ZIP 用微信、网盘发给对方即可。对方解压后 Windows 双击 `start.bat`、Mac 双击
`start-mac.command`；包里附了一份写给对方看的 `使用说明.txt`（装 Python、系统拦截怎么放行、
怎么填 Key、怎么更新）。每个人在自己的「设置」里填自己的 API Key，模型费用各付各的。
文件夹要放在不会同步到云盘的位置（Mac 的个人文件夹、Windows 的 C:\touyan 之类），放进 iCloud / OneDrive 同步的桌面或文稿里，几百 MB 的依赖和数据库会被反复同步，可能导致打不开。

**不要把自己电脑上的 `touyan` 文件夹直接压缩发出去**：`.venv/` 是本机装的依赖，几百 MB，换一台电脑也用不了；
1.1 及更早的版本还把 API Key 存在文件夹里的 `data/settings.json`，发出去别人就能用你的额度。
打包脚本只收运行需要的文件（不含 `data/`、`.venv/`、测试、Dockerfile），`tests/test_package.py`
会检查这一点。

对方更新到新版本：解压新包，直接从新文件夹启动，旧文件夹删掉即可（把旧文件夹整个替换掉也行）。
设置、API Key 和历史记录不在程序文件夹里（见下面「数据存在哪」），换版本不用重新填。
启动脚本按内容比对 `requirements.txt`，依赖有变化会自动补装，直接覆盖旧文件也没问题。

### 数据存在哪

设置（含 API Key）、历史记录、每日精选的存档和行情缓存，都放在**个人文件夹下的 `.touyan`**
（Mac：`/Users/你的用户名/.touyan`；Windows：`C:\Users\你的用户名\.touyan`），启动时终端里会打印这个位置，
「设置」页里也写着。程序文件夹里只有程序本身：换新版本、换位置、整个替换掉，设置都还在。

1.1 及更早的版本把这些存在程序文件夹的 `data/` 里，于是换一个新解压的文件夹、或者把文件夹整个替换，
API Key 就丢了；放在 iCloud / OneDrive 同步的目录里还可能读不出来。升级后第一次启动时，
程序会把所在文件夹里的 `data/` 自动搬到新位置（新位置已有内容的文件不会被覆盖）。
要放到别处，设置环境变量 `TOUYAN_DATA_DIR`（Docker 镜像里是 `/data`）。

另外两处保护：设置文件一时读不出来时不会用默认值把它覆盖掉（保存会被拒绝并提示稍后再试）；
在原文件夹里覆盖更新后，如果更新前启动的旧程序还开着，新程序会自动换一个端口启动并提醒关掉旧窗口，
不会再把人带到旧版本的页面上。

想让别人不用安装、打开网址就能用，见下一节：那样模型费用走你的 Key，务必设置访问密码；
如果要收费，先看文末「合规」一条。

## 部署到服务器

服务器上**务必设置访问密码** `APP_PASSWORD`。没设置时，深度分析和修改设置只允许本机访问——
大模型按调用计费，暴露到公网就会被别人刷光额度（原站 README 里提到的那个漏洞）。
设置后浏览器会弹出登录框，用户名随意，密码填 `APP_PASSWORD`。

Docker（构建目录选 `touyan/`）：

```bash
docker build -t touyan ./touyan
docker run -d -p 8600:8600 -v touyan-data:/data \
  -e APP_PASSWORD=换成你的密码 -e DEEPSEEK_API_KEY=sk-xxx touyan
```

**腾讯云 CloudBase 云托管**：新建一个服务（和八字站分开），代码目录选 `touyan`，它会识别这里的
Dockerfile；环境变量里加 `PORT=80`（云托管默认监听 80）、`APP_PASSWORD`、大模型 Key。
和原站一样，跑不了「静态网站托管」。

所有可配置项见 `.env.example`。

## 局限与风险（请读）

- **评分规则没有经过回测验证**，只是把常见的分析框架写成了明确、可检查的规则。
  它告诉你「当前数据呈现什么特征」，不预测涨跌。
- **大模型会出错**：误读数据、过度自信、前后矛盾都可能发生。提示词要求它只引用核验过的数字，
  能减少但不能杜绝编造。
- 数据来自非官方接口，可能延迟、缺失或出错；盘中数据未收盘。
- 历史复盘的样本少时没有统计意义，短期结果受偶然因素影响很大。
- **合规**：在中国大陆，向不特定公众提供证券投资建议（尤其是收费荐股）需要证券投资咨询业务资格。
  本工具适合个人研究使用；**把每日精选的结果收费推送给别人，就属于荐股**。如果要对外提供服务，请先确认合规要求。
