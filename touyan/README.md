# 投研智能体

股票、基金、ETF、指数的分析软件。两层能力：

- **量化体检**（免费、几秒出结果、不用大模型）：K 线与指标、收益风险、估值与财务、
  基金经理与规模，汇总成六个维度的评分和五档评级，**每一分都列出依据**。
- **AI 多智能体深度分析**（需要一个大模型 API Key）：把开源项目
  [TradingAgents](https://github.com/TauricResearch/TradingAgents) 的投研团队搬过来——
  技术面、基本面、资讯三位分析师并行写报告 → 多头与空头研究员辩论 → 研究主管形成投资计划
  → 交易员给出入场、止损和仓位 → 激进、保守、中性三位风控辩论 → 投资经理拍板。
  每个智能体的发言在网页上实时滚动出来。

覆盖 A 股（沪深京）、港股、美股、场内 ETF/LOF、场外公募基金、主要指数；
数据源覆盖不到的产品（银行理财、私募、自己记的净值）可以导入 CSV 分析。

> ⚠️ 仅供研究与学习参考，不构成投资建议。模型和数据都可能出错。

## 快速开始

需要 Python 3.10 或更高版本（3.10 – 3.14 都测试过，3.15 预览版也能跑）。

**Windows**：双击 `start.bat`。
**macOS**：双击 `start-mac.command`（被系统拦下时，到「系统设置 → 隐私与安全性」底部点「仍要打开」）；
或者在终端进入 `touyan` 文件夹，运行 `bash start.sh`。**Linux** 同样运行 `bash start.sh`。
macOS 自带的 python3 是 3.9，太旧；脚本会自动找已安装的新版本，找不到会提示去
[python.org](https://www.python.org/downloads/) 下载安装。

第一次会自动创建虚拟环境、安装依赖（优先走清华镜像，失败自动换官方源），之后秒开，
浏览器打开 http://127.0.0.1:8600 。

手动安装也可以：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

不配置大模型也能用全部量化功能。要用 AI 深度分析，打开「设置」，选一家服务商、粘贴
API Key、点「测试连接」。推荐 **DeepSeek**：国内直连、便宜；默认一次完整分析 11 次模型调用
（辩论轮数调到最大时 21 次），通常 2–8 分钟。

| 服务商 | 网络 | 默认快模型 / 深度模型 |
|---|---|---|
| DeepSeek | 国内直连 | deepseek-flash / deepseek-v4-pro |
| 通义千问（阿里云百炼） | 国内直连 | qwen3.8-flash / qwen3.8-max |
| 智谱 GLM | 国内直连 | glm-5.3-flash / glm-5.3 |
| Kimi（月之暗面） | 国内直连 | kimi-k2.6 / kimi-k3 |
| MiniMax、硅基流动 | 国内直连 | 见设置页 |
| Claude（Anthropic 官方 SDK） | 需代理或中转 | claude-opus-5-5 / claude-opus-5-5 |
| OpenAI、Gemini、OpenRouter | 需代理 | 见设置页 |
| Ollama（本机模型） | 离线 | qwen3:latest |
| 自定义（任何 OpenAI 兼容接口） | — | 自己填 |

「快模型」负责分析师、研究员、交易员和风控辩手（调用次数多），「深度模型」负责研究主管和
投资经理（做最终判断）——和 TradingAgents 的 quick / deep 两档一致。模型名可以随便改，
下拉列表只是建议。

Claude 走 Anthropic 官方 SDK：不传 temperature（新版 API 会拒绝），推理深度用「推理强度」
（effort）控制，默认 high；直连官方 API 时默认开启服务端回退（`fallbacks: "default"`），
请求被安全策略拒绝时由 Anthropic 自动交给推荐的备用模型重跑。走中转地址时不开启。

## 能做什么

### 量化体检

| 维度 | 看什么 |
|---|---|
| 趋势 | 均线排列、价格与 60 日线 / 年线的关系、MACD 所在区域 |
| 动量 | 20 / 60 日涨跌、MACD 与 KDJ 交叉、RSI、量价配合、布林带位置 |
| 风险 | 年化波动、最大回撤、贝塔、单日 VaR（分数越高风险越低） |
| 估值 | 动态市盈率、市净率、PEG |
| 质量 | ROE、毛利率、净利率、负债率、经营现金流 / 利润 |
| 成长 | 营收与净利润增速、扣非差异、增速加快还是放缓 |

基金换一套维度：**业绩**（相对基准、同类排名、三年年化）、**回撤控制**、**性价比**（夏普、卡玛）、
**稳定性**（经理任期、规模、持仓集中度）、趋势。ETF 和指数只看趋势、动量、风险（ETF 加规模）。

打分规则写死在代码里，口径刻意保守：

- 每个维度从中性 50 分起，按信号加减，夹在 5–95，**每一分都对应界面上的一条依据**。
- 缺数据的维度不参与加权，同时降低置信度——不拿 50 分冒充。
- 两处容易算错的口径专门处理了：A 股季报的 ROE 是累计值（一季报只有全年约 1/4），
  打分前先按报告期年化；银行、保险等金融企业不评负债率和毛利率。
- 估值只看绝对水平，**没有做同行业对比**，依据里会写明这一点。

指标口径对齐通达信 / 东方财富（MACD 柱 = 2×(DIF−DEA)、KDJ 9-3-3、RSI 用 Wilder 平滑），
开发时与 TradingAgents 用的 stockstats 逐值比对过。收益一律用复权价：股票取前复权，
基金用每日「净值回报」连乘出复权净值——直接拿单位净值算，分红会被算成亏损。

### AI 深度分析（TradingAgents 架构）

| 阶段 | 角色 | 产出 |
|---|---|---|
| ① 分析师团队（并行） | 技术分析师、基本面分析师（基金为基金研究员）、资讯分析师 | 三份报告 |
| ② 研究团队 | 多头研究员 ⇄ 空头研究员，辩论 1–3 轮 → 研究主管 | 投资计划与评级 |
| ③ 交易员 | 交易员 | 操作方向、入场价、止损价、目标价、仓位 |
| ④ 风控团队 | 激进型 → 保守型 → 中性，辩论 1–3 轮 | 风险审议 |
| ⑤ 决策 | 投资经理 | 最终五档评级、目标价、持有期、信心 |

和原项目相比的几处取舍：

- **分析师不走工具调用。** 程序先把数据取齐、算好，写成「核验数据简报」放进提示词，模型只负责解读，
  并被要求「引用具体数字时以简报为准、简报里没有的不要写」。国产模型的工具调用稳定性参差不齐，
  这样更稳、更省钱，也从根上避免了编造价格（原项目 #830 讨论过的问题）。
- **不依赖 LangGraph。** 编排是一段直白的 Python 流程，逐字推送到网页（SSE）。
  任务在后台跑，刷新页面或断网重连都不会中断。
- **保留了原项目踩坑后加上的规则**：「有分歧」不是持有的理由；对手还没发言时明确告诉模型
  先陈述己方观点（否则它会编一个对手论点来反驳）；价格必须写绝对值；读不出评级就记为
  「待复核」，绝不默认成「持有」；交易员给出的价位方向不对或离现价太远会被标注出来。
- **记忆与复盘**：每次结论都存档；投资经理分析同一标的时，会读到过往结论和之后的实际涨跌。

可以填上自己的持仓（数量、成本、可用资金），交易员和投资经理会给出针对这笔仓位的操作；
不填时会被明确告知「不知道用户持仓，不要假设空仓」。

### 其他

- **多品种对比**：最多 6 个，股票、基金、指数可混合。同一纵轴的累计收益（起点归一为 0%，
  不做双纵轴）、关键指标、日收益相关系数（只用双方都交易的日子）。
- **历史与复盘**：每次深度分析的结论 + 之后的实际收益与同期超额收益，统计方向正确率。
  口径：分析当日收盘买入，持有到最新收盘，在同一条复权序列里取价。
- **导入 CSV**：只要「日期」和「收盘价/净值」两列，中英文表头、UTF-8/GBK 都认。
- **导出**：量化报告和 AI 报告都能下载 Markdown，或直接打印 / 另存 PDF。
- **命令行**：

```bash
.venv/bin/python cli.py analyze 600519            # 量化体检
.venv/bin/python cli.py analyze 110011 --deep     # AI 深度分析，终端实时输出
.venv/bin/python cli.py search 茅台
.venv/bin/python cli.py doctor                    # 自检：数据源与大模型配置
```

## 代码怎么写

| 写法 | 例子 |
|---|---|
| A 股 | `600519`、`sh600519`、`600519.SH`、`300750`、`830799`（北交所） |
| 港股 | `00700`、`700.HK`、`hk00700` |
| 美股 | `AAPL`、`BRK.B`、`us.TSLA` |
| 场内 ETF / LOF | `510300`、`159915` |
| 场外基金 | `110011`、`005827`、`of000001` |
| 指数 | `sh000001`、`399006`、`沪深300`、`恒生指数`、`标普500` |
| 名称 / 拼音 | `茅台`、`腾讯`、`易方达蓝筹`（需要能访问搜索接口） |

6 位数字有歧义（`000001` 既是平安银行、上证指数，也是一只场外基金），搜索框会把几种可能
都列出来；也可以在搜索框右侧直接指定品种。

## 数据从哪来

| 数据 | 首选 | 备用 |
|---|---|---|
| K 线 | 东方财富 | 腾讯证券（A 股、港股）→ akshare → yfinance（这两个需另装） |
| 基准指数 | 腾讯证券 | 东方财富 |
| 行情快照与估值 | 东方财富 | 腾讯证券 |
| 财务指标 | 东方财富数据中心（A 股、港股、美股） | — |
| 基金净值、规模、经理、持仓 | 天天基金 | — |
| 基金类型、基金公司、业绩基准 | 蛋卷基金 | — |
| 个股新闻 / 市场快讯 | 东方财富 | 新浪财经 7x24 |

这些都是网页在用的公开接口，**没有官方文档，随时可能变**。接口地址、参数和字段含义参照
akshare（2026-11 版）的实现；字段含义没有经过它印证的一律不用。

几条保护措施：

- **东方财富 push2 限流熔断。** 它对密集请求会直接断开连接、封 IP 几分钟到几十分钟，此时重试只会
  延长封禁。程序识别到后会在 6 分钟内自动改走腾讯等备用源；基准指数本来就优先走腾讯，分散压力。
- **缓存 + 旧数据兜底。** 行情缓存 15 分钟；所有数据源都失败时，用最近一次缓存并明确标注
  「X 小时前的缓存」。
- **辅助数据取不到不影响主流程**，页面上会列出缺了什么，智能体也会被告知「本次没有新闻」，
  而不是拿空白当作「没有利空」。
- 网络环境千差万别：**「设置 → 数据源自检」**（或 `cli.py doctor`）逐个探测每个数据源，
  哪个通、哪个不通一目了然。

## 分享给别人

```bash
cd touyan
python3 make_package.py        # 生成 dist/touyan-日期.zip，约 170 KB
```

把这个 ZIP 用微信、网盘发给对方即可。对方解压后 Windows 双击 `start.bat`、Mac 双击
`start-mac.command`；包里附了一份写给对方看的 `使用说明.txt`（装 Python、系统拦截怎么放行、
怎么填 Key、怎么更新）。每个人在自己的「设置」里填自己的 API Key，模型费用各付各的。

**不要把自己电脑上的 `touyan` 文件夹直接压缩发出去**：`data/settings.json` 里是你的 API Key，
发出去别人就能用你的额度；`.venv/` 是本机装的依赖，几百 MB，换一台电脑也用不了。
打包脚本只收运行需要的文件（不含 `data/`、`.venv/`、测试、Dockerfile），`tests/test_package.py`
会检查这一点。

对方更新到新版本：解压新包，把旧文件夹里的 `data` 文件夹复制进去（设置和历史都在里面）。
启动脚本按内容比对 `requirements.txt`，依赖有变化会自动补装，直接覆盖旧文件也没问题。

想让别人不用安装、打开网址就能用，见下一节：那样模型费用走你的 Key，务必设置访问密码；
如果要收费，先看文末「合规」一条。

## 部署到服务器

服务器上**务必设置访问密码** `APP_PASSWORD`。没设置时，深度分析和修改设置只允许本机访问——
大模型按调用计费，暴露到公网就会被别人刷光额度（原站 README 里提到的那个漏洞）。
设置后浏览器会弹出登录框，用户名随意，密码填 `APP_PASSWORD`。

Docker（构建目录选 `touyan/`）：

```bash
docker build -t touyan ./touyan
docker run -d -p 8600:8600 -v touyan-data:/data \
  -e APP_PASSWORD=换成你的密码 -e DEEPSEEK_API_KEY=sk-xxx touyan
```

**腾讯云 CloudBase 云托管**：新建一个服务（和八字站分开），代码目录选 `touyan`，它会识别这里的
Dockerfile；环境变量里加 `PORT=80`（云托管默认监听 80）、`APP_PASSWORD`、大模型 Key。
和原站一样，跑不了「静态网站托管」。

所有可配置项见 `.env.example`。

## 局限与风险（请读）

- **评分规则没有经过回测验证**，只是把常见的分析框架写成了明确、可检查的规则。
  它告诉你「当前数据呈现什么特征」，不预测涨跌。
- **大模型会出错**：误读数据、过度自信、前后矛盾都可能发生。提示词要求它只引用核验过的数字，
  能减少但不能杜绝编造。
- 数据来自非官方接口，可能延迟、缺失或出错；盘中数据未收盘。
- 历史复盘的样本少时没有统计意义，短期结果受偶然因素影响很大。
- **合规**：在中国大陆，向不特定公众提供证券投资建议（尤其是收费荐股）需要证券投资咨询业务资格。
  本工具适合个人研究使用；如果要对外提供服务，请先确认合规要求。
