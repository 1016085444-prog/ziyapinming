# 每日精选的研究底稿

短期、中期两个板块的方法不是拍脑袋定的。这个文件夹是定方法时用的全部脚本和最后的结果数字，
放在这里是为了能复核：任何一条写在软件页面上的统计，都能在这里找到是怎么算出来的。

软件运行不需要这个文件夹，分享给别人的安装包里也不带它。

## 用了什么数据

- 沪深两市 5562 只股票（含 338 只已经退市的）2005–2026 年的日线，腾讯证券。只用活下来的股票做检验，结果会虚高，所以把退市的也下载了。
- 复权：腾讯的「前复权」是减法复权（把历年分红直接从价格里减掉），时间一长算出来的涨跌幅是错的
  （茅台 2016 年的前复权价只有 20 多元）。这里用不复权价 + 除权除息记录还原成等比复权，
  3.7 万次除权除息里有 99.7% 用两种算法互相印证过（`adjust.py`）。
- 历年业绩报表、业绩预告（带公告日期），东方财富数据中心。
- 主要指数 2005 年以来的日线。

数据有几百 MB，不放进仓库。要重新下载：`fetch.py`（近十年在市股票）、`fetch_delisted.py`、`fetch_raw.py`（不复权 + 除权记录）、
`fetch_old.py`（2005–2016）、`fetch_misc.py`、`fetch_yjbb_old.py`、`fetch_index_long.py`，然后 `panel2.py`、`panel_old.py` 拼成大表。

## 检验的口径

和软件里一致，刻意按吃亏的算：信号在收盘后才知道，**第二天开盘买**；开盘就涨停的买不进；当天买的当天不能卖（T+1）；
封死跌停卖不掉，顺延到下一天开盘；每笔扣 0.2%（手续费 + 印花税 + 滑点）。
每个结果都和「同一天在同一批股票里随便买」比，并且分年度看，再分成两个十年（2005–2016、2016–2026）各看一遍——
只在一个十年里成立的不算。工具在 `lab.py`、`feat.py`。

## 结论（按实验顺序）

| 实验 | 问题 | 结论 |
|---|---|---|
| `exp02` | 原来的「错杀反弹」「悄悄走强」行不行 | 不行。前者十年里每笔比随便买少赚 0.2%–0.4%；后者时好时坏 |
| `exp03` `exp17` | 几十种量价线索，哪些有用 | 作用几乎全在「该躲开什么」：高换手、放量、盘中拉升的股票之后明显跑输。「跌多了会反弹」在平常日子不成立 |
| `exp04` | 买入方式 | 隔夜平均亏、盘中平均赚（22 年一直如此）。低开时买比高开时买好，但幅度很薄 |
| `exp05` | 业绩公告后的漂移 | 2017–2020 年很强，2021 年以后被套利掉大半 |
| `exp07`–`exp09` `exp16` `exp18` | 大跌后抄底 | 「跌多了就抄」在 2008、2015 年连续亏损；「出现大面积跌停之后」才是跨 22 年成立的 |
| `exp11` | 日历效应 | 月末最后一天到下月第一天，指数平均 +0.5%–0.6%，四个时间段全为正；其余日子接近零 |
| `exp20` | 涨停股的「次日指数一直涨」 | 指数是真的（次日收盘平均 +1.8%），但几乎全来自开盘高开，买不到。次日开盘买入的平均亏 1%，打板平均亏 0.6% |
| `exp21` `exp22` | 收盘后能不能预估大盘 | 能。放量、大涨大跌、涨停跌停多、月末月初之后偏强；平淡缩量之后偏弱。打成分数后跨十年检验成立 |
| `exp23` | 大小盘、板块能不能预判 | 大小盘有惯性；板块没有「追强」的规律，当天涨停最集中的板块之后反而跑输 |
| `exp24` `exp25` | 分数高的日子买什么 | 近期跌得多、离高点远、没人追捧的。同样的选法每天都用则没有优势 |
| `exp12` `exp13` `exp19` `exp26` `exp27` `exp29` | 中期方法 | 「冷热分」最冷的一成 + 中小市值 + 赚钱 + 利润增长；最热的一成 22 年里每年都跑输 |
| `exp30`–`exp32` | 最终规则的数字 | 见 `results/ship_new.json`（2016.8–2026.11）、`results/ship_old.json`（2005–2016.7） |

## 第二轮：长期、定投、市场温度、行业（实验 40–57）

| 实验 | 问题 | 结论 |
|---|---|---|
| `exp40` `exp41` `exp57` | 长期买什么 | 赚钱 + 有分红 + 三年 ROE 不低于 8% + 利润没大降 + 不属于「四种热」的「稳健名单」；ROE 越高越好并不成立 |
| `exp42` `exp43` | 能不能量整个市场贵不贵 | 「市场温度」：全市场和大盘股中位数市净率在之前十年里的排位。温度 40 以下买入拿两年几乎都赚，80 以上买入没有赚过 |
| `exp44` `exp45` | 按温度进出 | 中证全指「低于 40 买、高于 80 卖」18 年半换 9 次仓，年化 +1.5% → +10.1%，最大回撤 60% → 35% |
| `exp46`–`exp48` | 定投 | 宽基指数基金按温度卖出、再投回，年化 3%–7% → 9%–12%；红利、美股指数一直投不卖最好；目标止盈没有稳定好处 |
| `exp53` | 主动基金能不能按业绩挑 | 不能：过去 3 年最好的五分之一，之后 3 年比同类少赚 |
| `exp54`–`exp56` | 冷了很久的行业会不会补涨 | 不会：连续跑输 4 年以上的行业之后继续跑输；行业是强者恒强。只对长期有用（去掉长期走弱的行业） |
| `exp52` | 四个板块的最终数字 | 见 `results/ship3_new.json`、`results/ship3_old.json` |

## 第三轮：短期、中期再挖一遍（实验 60–67）

| 实验 | 问题 | 结论 |
|---|---|---|
| `exp60` | 出手的日子里，候选股之间哪些特征决定输赢（60 多个） | 近期跌得多、比同行业跌得多、贝塔高、没放量、收盘在低位、冷的更好；基本面在 5 天里几乎没作用 |
| `exp61` | 把这些加进短期排序 | 选出来的 5 只每笔最多差零点几个点，两个十年方向不一致——选股已经挖到头，没改 |
| `exp62` | 出手时机还能不能更准 | 分数越高越好；同样的分数，市场越冷越好；分数 2 且温度 60 以上的日子两个十年都不赚钱 |
| `exp63` `exp64` `exp66` | 中期：冷门股里什么决定之后一到三个月 | 「业绩超预期」（最新单季利润比去年同季多出的部分 ÷ 流通市值）两个十年都成立，更早的十年 11 年年年为正；成交额小、近期没涨停也有用 |
| `exp65` | 入选名次有没有意义；拿几天、选几只、按波动分仓 | 名次和之后的收益没有关系（几只应该等额买）；选 5 只和 10 只差不多；按波动分仓没好处 |
| `exp67` | 第三轮定稿后的数字 | 见 `results/ship4_new.json`、`results/ship4_old.json`：短期「把握大」的日子 +3.8% / +3.3%、两个十年都没有亏钱的年份；中期按时机建仓 +7.8% / +11.0% |

`xlab.py` 是第三轮新加的工具（行业层面的量、贝塔、财报比值、「只在某些日子里」的分组检验）。

## 局限

- 这些是历史统计，不是承诺。2015 年那种连环暴跌里，短期方法的一篮子股票 5 天亏过 20% 以上。
- 中期方法在 2005–2016 年只比随便买略好，是 2017 年以后才变强的——它适合现在的市场，不保证永远有效。
- 财报数据用的是现在能查到的数值，个别公司事后改过数；涨跌停是按规则推算的，ST 股票用近似办法识别。
